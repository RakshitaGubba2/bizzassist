📋 NVIDIA NIM API Key Setup

Step 1: Open the .env file in your project root folder

Step 2: Go to https://build.nvidia.com/ and log in

Step 3: Find the google/gemma-4-31b-it model and click "Get API Key"

Step 4: Copy the API key and paste it in the .env file:

NVIDIA_NIM_API_KEY=your_api_key_here

Step 5: Restart the application
